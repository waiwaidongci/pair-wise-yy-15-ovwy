# hxyfront-62014 拼车训放席位台

几个鸽棚拼车训放时的席位管理工具，替代群里接龙记笼位。

## 业务规则

- 管理员创建车次：训放点、路线、出发时间、司放员、可载笼数。
- 每个足环占一个笼位；满员后按确认顺序进入候补。
- 退位时最早候补自动补上，原报名留档不删除。
- 司放员或路线变化后，已确认票失效，需重新确认（仅改期不影响）。
- 列表支持按车次、按足环两种视角查看，全部动作留档可查。

## 代码结构（三个业务文件）

- `src/rules.ts` — 业务规则：车次、报名、候补、退位递补、票失效与重新确认。
- `src/archive.ts` — 存档：留档记录类型、localStorage 持久化、演示数据。
- `src/App.tsx` — 页面：开车次 / 报名表单、车次卡片、按足环查询、留档列表。

## 技术栈

React + Vite + TypeScript
